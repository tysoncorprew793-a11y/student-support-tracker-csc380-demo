# Student Support Tracker

A classroom example repository for CSC 380 Software Engineering at Norfolk State University.

## Project Goal
Help students submit and track requests for academic or technical support.

## Initial Requirements
- Students can submit support requests.
- Students can view their requests.
- Support staff can review requests.

## Workshop
This repository is used to demonstrate Git branches, pull requests, code review, merging, and synchronization.

> Demonstration files only. No real student data or passwords.
